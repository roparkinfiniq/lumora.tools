# Lumora Tools - Project Guidelines & Rules

## Language Requirement (CRITICAL)
- **Target Audience**: Global / international users.
- **Strict English UI**: All user-facing UI copy, buttons, badges, modals, toast messages, tooltips, placeholders, headings, descriptions, and blog posts MUST be written in **natural, fluent English**.
- **Communication vs Code**: While conversation with the project owner in the chat assistant can take place in Korean, **all frontend code, text content, and user-facing assets must strictly be in English**.

## Product Information
- **Apps (in this order)**: Doquarium (neon to-do aquarium app for Android & iPhone, shown first across the site) and Code Tiara (focus desktop application for macOS and Windows).
- **More rules**: see `CLAUDE.md` (site map, SEO, performance, deploy) and `TOOL_GUIDELINES.md` (tool design).
- **Brand Identity**: Clean, luxury, minimal, distraction-free aesthetic with dark glassmorphism and subtle glowing neon accents (`#c084fc`, `#ff7eb3`).
